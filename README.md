# Ayni Sana - Produtos Naturais 🌿

<br>

<h2>Este foi um projeto inspirado nos conceitos aprendidos no <a href="https://rodolfomori.com.br/devclub">DevClub</a></h2>

<br>

### 📝 Sobre o projeto:
A **Ayni Sana** é uma landing page desenvolvida para uma loja de produtos naturais e bem-estar. O projeto foi construído com foco total na **experiência de compra do usuário**, utilizando uma estética "Boho" e botânica para transmitir calma e conexão com a natureza.

O layout destaca o florescer pessoal e o autocuidado, integrando elementos visuais que guiam o cliente desde a descoberta da marca até a vitrine de produtos.

---

### 🛠 Tecnologias utilizadas:

* **HTML**: Estruturação semântica do conteúdo.
* **CSS**: Estilização personalizada, uso de Flexbox para responsividade e variáveis para paleta de cores.
* **Google Fonts**: Implementação das fontes *Playfair Display* e *Poppins* para elegância e legibilidade.
* **Organização de Ativos**: Estrutura de pastas profissional utilizando a pasta `assets/`.

---

### 🎨 Identidade Visual:
O projeto utiliza uma paleta de cores terrosas e naturais:
* **Verde Folha**: Simbolizando saúde e natureza.
* **Terracota**: Trazendo calor e acolhimento.
* **Creme**: Proporcionando leveza ao fundo da página.

---

### 🚀 Como visualizar:
1.  Faça o download ou clone este repositório.
2.  Certifique-se de que as imagens estão na pasta `/assets`.
3.  Abra o arquivo `index.html` em seu navegador de preferência.
